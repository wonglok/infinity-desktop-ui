# Infinity Cloud — Desktop UI

## Brand personality
Clean, functional, calm. A desktop environment that feels familiar but refined — frosted glass, soft shadows, and a restrained purple accent. macOS-inspired translucency without copying it.

## Platform
web (Next.js 16, React 19, Tailwind CSS v4, Zustand)

## Register
product (app UI — desktop environment simulator)

## Visual identity
- **Palette**: near-white warm base (#f7f5f8), translucent glass surfaces (rgba(255,255,252,0.6–0.82)), deep ink (#1d1a28), soft mid-tones (#3d3a4d, #5e5a70, #4a4658)
- **Accent**: purple (#7c6fd4 / rgba(124,111,212,0.55–0.82))
- **Error**: red (#c41e1e on rgba(239,68,68,0.06))
- **Type**: Geist Sans (body/UI), Geist Mono (terminal/code)
- **Surface**: frosted glass (blur 24-32px, saturate 140-160%), soft inset highlights, rounded corners (10-22px), subtle box shadows with warm tint (rgba(80,60,100,0.06–0.14))
- **Radii scale**: 10px (small buttons), 12px (inputs/buttons), 14px (form elements), 18px (windows), 20-22px (modal, login card)

## Anti-references
- Avoid heavy/dark UI — this is light, airy, translucent
- Avoid high-saturation colors — the palette is muted and refined
- Avoid flat opaque surfaces — glass and translucency are core to the identity
- No brutalist or terminal-native dark mode as default
